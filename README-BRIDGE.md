# urSovngarde + SkyrimNet bridge

This is a fork of [urSovngarde](https://github.com/OhLookItsDaOne/urSovngarde) (Skyrim VR co-op,
GPLv3) that adds a compatibility bridge for [SkyrimNet](https://github.com/MinLL/SkyrimNet-GamePlugin)
(AI NPC dialogue), so that in co-op every NPC has one AI mind and both players can talk to it and
hear it.

- Upstream's own README: [`README.md`](README.md)
- Project brief for contributors and AI sessions: [`CLAUDE.md`](CLAUDE.md)
- Plan, task list, decisions, test log: [`docs/bridge/`](docs/bridge/README.md)
- Work happens on the `skyrimnet-bridge` branch; `main` mirrors upstream.

Status: planning complete, no bridge code yet. SkyrimNet itself is **not** included and never will
be; install it from its official pages.
